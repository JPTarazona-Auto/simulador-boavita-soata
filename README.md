# Simulador Boavita → Soatá

Simulador de manejo 3D para el celular por la carretera real entre Boavita y Soatá (Boyacá, Colombia): 23.8 km, bajando al cañón del Chicamocha y subiendo otra vez.

**Jugar:** https://jptarazona-auto.github.io/simulador-boavita-soata/

- Flechas a la izquierda para girar; acelerador y freno a la derecha. En computador, teclas de flecha.
- Opcional: girar inclinando el celular (giroscopio). Se marca en la pantalla de inicio.
- Tráfico simulado, límites de velocidad con multas y postales con fotos reales del recorrido.
